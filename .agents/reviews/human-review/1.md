# Codebase Tour & Review Guide

## 1. Core Domain Contracts (`/`)
Start here to understand the base abstractions:
- **`stream.go`**: Core generic interfaces — `Receiver[T]`, `Sender[T]`, `Stream[T]`, and closers (`ReceiverCloser`, `SenderCloser`, `StreamCloser`).
- **`sentinels.go`**: Foundational in-memory building blocks — `ChanStream[T]` (Go channel adapter with context cancellation guards) and sentinels (`NoopSender`, `NoopReceiver`, `EOFSender`, `EOFReceiver`).
- **`sentinels_test.go`**: Table-driven tests validating context cancellation and clean channel closure.

---

## 2. Push vs Pull Interoperability (`examples/`)
- **`examples/push_pull_test.go`**: Demonstrates zero-cost conversion between push-based `Receiver[T]` and Go 1.23 standard pull iterators (`iter.Seq2[T, error]`).

---

## 3. Operators Layer (`operators/`)
Examine stream combinators and transformations in order of complexity:
- **`operators/transformations/`**:
  - `Map`, `FlatMap`, `Filter`, `Reduce`, `Batch` (size + timeout flushing).
- **`operators/merging/`**:
  - `Merge`: Fan-in with error group cancellation.
  - `Zip`: 1:1 stream pair synchronization.
  - `MergeSort`: Multi-partition k-way merge using `container/heap`.
- **`operators/routing/`**:
  - `Broadcast`: Concurrent fan-out.
  - `RoundRobin`: Cyclic distribution across workers.
  - `Partition`: Key-routed sharding via lookup map.
- **`operators/control/`**:
  - `Throttle`: Ticker-based rate limiting.
  - `Debounce`: Burst squashing with quiet-window timers.
  - `RetrySender`: Resilient send wrapper with backoff.
- **`operators/math/`**:
  - Pure function wrappers (`func(I) O`) that panic on transport errors.

---

## 4. Adapters & Transport Layer (`adapters/`)
How external I/O protocols plug into the `Receiver`/`Sender` contracts:
- **`adapters/jsonl/`**: Streaming JSON lines over standard `io.Reader` and `io.Writer`.
- **`adapters/objectstorage/`**: GCS/S3 streaming connector reading and writing JSONL objects.
- **`adapters/http/`**: HTTP Server-Sent Events (`SSEStreamer`, `SSEReceiver`, `StreamToHTTP`).
- **`adapters/grpc/`**: Client and server streaming gRPC adapters.
- **`adapters/messaging/`**: Message broker bridge (`BrokerStream`) for Kafka and Cloud Pub/Sub.
